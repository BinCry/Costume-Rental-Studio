# Thin-plate Spline

`📐 Hình học` `🖼 Canvas 2D` `👕 Biến dạng trang phục`

Package triển khai phép biến dạng Thin-plate spline để căn ảnh trang phục theo các điểm neo trên cơ thể.

## Chức năng

- Tính toán phép nội suy Thin-plate spline.
- Biến dạng ảnh trên Canvas 2D.
- Hỗ trợ lưới nội suy phục vụ ghép trang phục.

## Biên dịch

Package được biên dịch cùng toàn bộ dự án:

```bash
npm run build
```

## Cấu trúc

```text
src/index.ts     Thuật toán Thin-plate spline và hàm xuất công khai
```
